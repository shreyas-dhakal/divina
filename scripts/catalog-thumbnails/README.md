# Catalog thumbnail generator

Run `npm install` and `npm run generate` from this directory. The script builds a disposable Vite + React + Tailwind v4 app in the system temp directory, initializes shadcn/ui, adds all listed components, and screenshots each rendered state with Playwright. For Thaw, shadcn-vue and shadcn-svelte, it navigates each docs site and captures the first live component preview. Every output is a centered 480×240 WebP in `public/catalog/`; a component whose docs preview cannot be captured has no image. Temporary project files are removed when generation ends. Set `CHROMIUM_EXECUTABLE` to override the Playwright Chromium found in `~/Library/Caches/ms-playwright`.
