# Catalog thumbnail generator

Run `npm install` and `npm run generate` from this directory. The script builds a disposable Vite + React + Tailwind v4 app in the system temp directory, initializes shadcn/ui, adds all listed components, and screenshots each rendered state with Playwright. For Thaw, it navigates the MIT-licensed Thaw UI docs and captures the matching component from its live example. Every output is a centered 480×240 WebP in `public/catalog/`; temporary project files are removed when generation ends. Set `CHROMIUM_EXECUTABLE` to override the Playwright Chromium found in `~/Library/Caches/ms-playwright`.
